## 📌 About The Project

This project is a fully responsive business website designed for a home interior company.  
It includes multiple pages like Home, About, Services, Projects, and Contact.

The goal of this project was to create a clean, professional, and user-friendly business website layout.

---

## 🛠️ Tech Stack Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons

---

## ✨ Features

- Responsive Navigation Bar
- Modern UI Design
- Services Section
- Project Gallery
- Contact Form
- Smooth User Experience
